A small native macOS companion for virtual shifting with **Wahoo KICKR v5 (2020), Zwift Cog, and Click 2**, with Zwift on the same Mac.

This is the first public preview. The app was previously named Velox.

### Download

Download **Veloshift-0.6.0-macOS-arm64.zip** below. Requires **Apple Silicon and macOS 14+**. GitHub’s “Source code” archives are for developers.

Quit older Velox/Veloshift instances, unzip, and move `Veloshift.app` to Applications. Existing profiles/settings carry over. This preview is ad-hoc signed, **not notarized**; if macOS blocks it, follow the per-app [Apple Open Anyway instructions](https://support.apple.com/en-us/102445) only if you trust this download.

### Features

- Bluetooth KICKR v5 control and Click 2 shifting, with a network trainer for Zwift.
- Compact window sized for use beside Zwift on one display.
- Saved rider profiles, profile deletion, even-effort gearing, and custom one/two-chainring drivetrains.
- Single-key shifting: **[ / ]**, with **J / K** alternative.
- Veloshift branding with a small vector road-bike mark.

### Setup

Connect hardware in Veloshift, start the bridge, then pair **Veloshift KICKR v5** with the network icon for Power Source, Resistance, and Cadence in Zwift. Unpair the physical trainer/controllers from Zwift first. See the repository README for full setup and Click 2 unlock limitations.

### Validation and known limits

All 29 automated check groups pass locally in debug/release. The companion layout, profile editor, and branding have been visually checked. Pairing and resistance control have been confirmed on the original rider’s hardware; compatibility across other firmware/Mac combinations remains limited. Keyboard delivery with Zwift focused still needs broader manual testing.

No proprietary Click unlock, native Zwift gear HUD, automatic reconnect, steering, or full drivetrain-inertia simulation. Commands are capped at 1,000 W. The local trainer network transport is unauthenticated and should be used on a trusted network. Failure-mode unloading needs further hardware tests. Intel is not a tested download target.

This project is independent of Zwift, Wahoo, and SRAM.
